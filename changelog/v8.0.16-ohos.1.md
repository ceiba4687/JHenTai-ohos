# JHenTai-ohos 8.0.16-ohos.1

基于上游 JHenTai `8.0.16`（versionCode `333`）的 HarmonyOS / OpenHarmony 移植版。

## 更新内容

- 同步上游 8.0.16，保留 HarmonyOS 工具链、插件适配及独立 Bundle ID。
- 适配新版标签编辑器：短窗口和横屏下可滚动，重置自定义标签颜色后正确恢复继承颜色。
- 关于页面标题更新为 `JHenTai-ohos`，保留原创作者，新增移植者 `ceiba4687` 和本仓库 GitHub 链接，移除 Telegram 群信息。
- 检查更新与下载入口改为本仓库的 GitHub Releases，支持 OHOS 修订版本号，并筛选附带 HAP 的正式版本。
- 删除 README 中的终端代理配置说明。

上游更新详情：[8.0.15](https://github.com/jiangtian616/JHenTai/blob/master/changelog/v8.0.15.md)、[8.0.16](https://github.com/jiangtian616/JHenTai/blob/master/changelog/v8.0.16.md)。

## 下载与安装

- 文件：`JHenTai-ohos-8.0.16-ohos.1-unsigned.hap`
- 架构：`ohos-arm64`
- 目标系统：HarmonyOS 7 / API 26；最低兼容 API 18。
- Bundle ID：`top.jtmonster.jhentai.ohos`，可与卓易通中的 Android 版共存。
- 应用内版本：`8.0.16`（`333`），与首个移植修订 `8.0.16-ohos.1` 等价。

本 Release 仅提供未签名 HAP，需要使用自己的 HarmonyOS 证书签名后安装。覆盖升级时请沿用原签名；Release 不包含签名证书或私钥。

从 8.0.14 升级后，首次启动会按上游逻辑优化本地下载索引；下载内容较多时，建议提前备份应用目录中的 `db.sqlite`。
